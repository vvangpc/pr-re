使用说明

一、项目说明

纯本地网页，不联网、不上传数据，判定在本地完成。

用于专利申请前快速比对两件事：

  1. 技术方案能否走 国家知识产权局「优先审查」；
  2. 能否走 地方保护中心「快速预审」（目前覆盖 成都 / 四川 / 重庆）。
结论仅供形式比对参考，最终以官方审查为准。

二、输入区

  • IPC 国际专利分类号：可填一个或多个。多个之间用 空格 / 逗号 / 顿号 / 分号 / 句号 / 回车 分隔；大小写不限（如 B60K6/10、H01M10/0563、G06F40/30）。
  • 关键词 / 摘要：可填关键词，也可直接粘贴一段摘要。多个关键词用 空格 / 逗号 / 顿号 / 分号 / 句号 / 回车 分隔；中文按宽松子串匹配。

三、按钮说明

① 优先审查查询（需 IPC + 关键词）

判定技术方案是否落入国家优先审查目录（“新三样”、关键数字技术、绿色技术、战略性新兴产业）。
规则：分类号匹配 且 关键词匹配。

结果分五档：

  • 完全命中：IPC 与关键词均命中，落入优先审查目录范围。
  • 需人工确认：IPC 命中，但该条目无关键词限定（如绿色技术目录）——不自动放行，请人工确认。
  • 疑似命中：IPC 命中，关键词列以“等”结尾且未显式命中——请人工复核。
  • IPC 在范围：IPC 落入分支，但所给关键词没对上——可调整关键词再判。
  • 未命中：该 IPC 不在任何目录范围内。

② 快速预审查询（只需 IPC）

按 IPC 小类查 成都 / 四川 / 重庆 三个保护中心的预审受理范围，显示命中的小类及所属产业领域：

  • 成都：生物 / 新材料
  • 四川：新一代信息技术 / 装备制造
  • 重庆：新一代信息技术 / 生物
注意：本工具只判断分类号是否落入预审受理范围，不代表该方案一定能通过预审。是否可预审，需由代理师结合创造性等实质条件自行判断。

③ 清空

清空两个输入框与全部查询结果。

④ 提取关键词

在关键词框粘贴摘要或一段话，从这段话中识别出与优先审查关键词词库对应的关键词，即如果这段话中有词语在关键词词库中，就会以标签显示（可删除非实际技术点的关键词）；确认后点「替换关键词」填回关键词框。

⑤ 匹配分类号（由关键词反查 IPC）

无分类号时，输入或提取关键词后点此，从优先审查目录反查候选 IPC 分类号，并附官方 IPC 分类表说明，便于识别：

  • 顶部 全部 / A…H 按钮按 IPC 部（大类） 筛选，括号内为该部候选数量；
  • 点候选号即填入 IPC 框（可多选累加），再去点「优先审查查询」或「快速预审查询」；
  • 2026.01 新分类号提示：目录沿用旧分类号，而 2026.01 版分类表对部分小类做了修订（主要是 H01L 半导体器件整体迁入新设的 H10 系列，例如 H01L31 光伏 → H10F、H01L33 发光 → H10H）。命中这类旧号时，会在该行标出对应的 2026.01 新分类号，便于到专利检索系统中使用。
反查 IPC 可能出现 IPC 小类词条较多，建议在专利查询网站查询与技术方案类似的专利文件，并复制其 IPC 分类号。

四、典型用法

  • 已知分类号：直接填 IPC（+ 关键词）→ 点「优先审查查询」或「快速预审查询」。
  • 只有技术方案：关键词框粘贴摘要 →「提取关键词」→「替换关键词」→「匹配分类号」→ 点候选号回填 IPC 框 → 优先审查查询 / 快速预审查询。

五、注意事项

  • 本工具仅作形式比对参考，结论不代表官方意见，最终以国家知识产权局 / 各保护中心审查为准。
  • 优先审查目录的关键词系人工整理，采用中文宽松子串匹配，可能存在漏判 / 误判，请务必人工复核。
  • 数据时点：优先审查目录依据各分类体系文件整理；保护中心预审范围依据成都 / 四川 / 重庆官方分类号表；IPC 分类表为 2026.01 版，可能出现无对应分类号的情况。
  • 全程本地运行，不联网、不上传。
